# 🚀 RealmHub: 开源·高性能·多节点 Realm 转发与端口段管理面板

> **完全开源可控**、基于 Go 语言构建的分布式控制平面，深度融合 **官方 Realm 原生内核** 与 **Linux 内核级 (iptables/nftables) 大端口段整段转发引擎**。

---

## 💡 重构背景与特性对比

原闭源项目（Zelay）由于代码不公开、无法定制，且底层纯用户态 Socket 绑定模式**无法应对 20000-50000 这样大跨度端口段转发**（会导致几万个文件描述符耗尽和内存崩溃）。

针对这些痛点，**RealmHub** 进行了彻底的现代化重构：

| 特性 | 原版 Zelay | RealmHub 重构版 |
| :--- | :--- | :--- |
| **开源状态** | 闭源二进制，不可控 | **100% 完全开源**，代码透明，自主可控 |
| **核心转发引擎** | 闭源魔改版 Realm | **官方开源 Realm 内核**（MIT 协议，经过大规模生产验证） |
| **端口段整段转发**<br>(如 20000-50000) | ❌ 不支持（单端口监听导致崩溃） | 🏆 **支持（内核双引擎调度）**：<br>• 单端口/常规端口走 Realm<br>• **大端口段自动下发 `iptables/nftables` 内核 DNAT** |
| **控制平面语言** | Rust (Axum) | **Go 语言**（跨平台交叉编译极简，维护门槛低） |
| **节点通信与同步** | 基础 WebSocket | **双向 WebSocket 长连接 + 心跳上报 + 规则热推送** |
| **持久化机制** | 简易 JSON | **纯 Go 线程安全原子存储**（免外部 DB 依赖） |
| **资源消耗** | 内存极低 | Agent 内存仅约 10MB~15MB，支持 1048576 高并发句柄 |

## 🚀 快速上手与编译

### 1. 本地编译

项目采用无 CGO 纯 Go 编写，支持直接在 Windows / Linux / macOS 下一键跨平台交叉编译：

```bash
# 编译本地可执行文件 (Windows / Linux)
go build -o realm-server ./cmd/server
go build -o realm-agent ./cmd/agent

# Windows 下跨平台编译为 Linux amd64 生产二进制文件
$env:CGO_ENABLED="0"; $env:GOOS="linux"; $env:GOARCH="amd64"
go build -o realm-server ./cmd/server
go build -o realm-agent ./cmd/agent
```

### 2. 部署管理面板 (Server)

在您的中控服务器上运行：
```bash
./realm-server -port 3000 -data ./data
```
* 打开浏览器访问：`http://服务器IP:3000`
* 首次访问自动引导创建管理员账号；
* 登录后进入控制台，可以在**节点管理**中添加节点，面板会自动生成专属的**一键安装命令**。

### 3. 部署受控节点 (Agent)

复制面板生成的命令到目标转发机器上执行，或手动运行：
```bash
./realm-agent --server "ws://控制端IP:3000/ws/agent" --secret "节点SECRET" --id "节点ID" --dir "./"
```
Agent 连接成功后将自动保持心跳并汇报负载，随时待命接收规则。

## 🔥 20000-50000 端口段转发使用方法

在 Web 仪表盘点击**“新增规则”**：
1. **所属节点**：选择目标服务器；
2. **转发工作模式**：选择 `🔥 内核级 iptables/nftables (大端口段 20000-50000 整段转发)`；
3. **传输协议**：支持选择 `TCP + UDP`（双协议同时支持）；
4. **本地监听端口**：输入 `20000-50000`；
5. **目标地址**：输入 `1.2.3.4:20000-50000`；
6. **点击保存**：
   * 控制端通过 WebSocket 即刻推送到 Agent；
   * Agent 立即向 Linux 内核专用 NAT 链（`REALM_HUB_PREROUTING` / `REALM_HUB_POSTROUTING`）注入 DNAT 映射规则；
   * **前端配置完成，后端在此端口段内随意开服或调整端口，前端完全免维护！**
